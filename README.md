# Android-Based Online Clearance System with ESP32 RFID Attendance

![Project Banner](./public/images/banner.png)

## 📌 Overview

This project is a BSIT Capstone Project developed to automate the student clearance process using RFID technology and ESP32.

The system allows students to check their clearance status digitally while providing administrators with an efficient way to manage records and approvals.

> **Note:** This repository contains my personal copy of our team capstone project for portfolio purposes.

---

## 🚀 Features

- RFID Student Identification
- Digital Clearance Management
- Student Dashboard
- Administrator Dashboard
- Firebase Integration
- Database Management
- Responsive Web Interface
